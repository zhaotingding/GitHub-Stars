# GitHub Stars++ 0.2.2 简明配置指南

这份说明只讲启动后需要填写的内容。现有电脑不用重装；新电脑安装见文末。

## 1. 打开已有程序

沿用原快捷方式，或打开已在运行的本机网页，默认地址为`http://127.0.0.1:8765/`。WSL已有环境可在源码根目录执行`bash tools/start_web.sh`；桌面入口为`bash tools/start_wsl.sh`。先确认能看到原来的项目，不要因为列表为空就删除数据。

## 2. 先关闭自动操作

首次使用先保持手动操作。在“设置 → 更多设置”里找到“定时检查”和“项目简介”，关闭自动检查及自动短分析；邮件也可先不启用。已有个人开关沿用旧值。

## 3. 配置模型与Key

进入“设置 → AI连接”，填写模型API Key和账户可用的“常用模型名称”。“更多模型与凭据设置”里的文本凭据来源选`local`，表示使用本程序的密钥；模型仍通过官方OpenAI接口调用。

想让问答和教程用同一个模型，点击“问答和教程也用这个模型”，再保存。需要分别设置时展开更多选项；读图模型单独填写，需支持图像。

勾选“开启AI功能”并保存。网页Key只用于当前服务，关闭程序后需重新提供；留空会保留已有Key。Windows原生桌面版可以使用系统凭据保存，WSL网页用local即可。

保存不代表认证成功，实际结果看“任务记录”。模型名称、价格和可用额度按自己的账户核实。

## 4. 换成自己的研究方向

在项目库点“设置关键词”，或到“设置 → 找项目的关键词”，每行写一个普通主题，例如：

```text
具身智能
embodied
vision-language-action
```

程序自动生成GitHub查询，原有高级条件会保留。熟悉后再展开高级查询修改语法。所有研究与热点查询合计最多8条，每次只取有限候选。

“我的学习方向”用于介绍基础和偏好，例如“有视觉基础，希望学习机器人感知”。其中的研究关键词影响推荐评分；修改查找主题后，也可以按需调整这些关注词。

## 5. 看懂预算再提问

“项目简介”“学习教程”“问答用量”三类限制独立。“问答用量”的文本/图片输入输出费率默认0，表示未知，会阻止相应新收费步骤；按账户价格填写人民币/百万Token费率。

研究默认每题最多3次模型调用、4次工具动作、1张图、180秒及0.50元本地估算。图片分析和Agent决策也占次数；预留按最大输出计算，实际回答短也可能不够下一步。金额不是账户硬上限，停止不能撤销已提交费用。历史试用参数不等于新安装默认值。

## 6. 保存后采集并核对结果

点击“保存设置”，回“项目库”点“查找新项目”，看找到的数量和具体消息。手上有GitHub链接时，用“添加指定项目”。先读项目，确实需要时再提一个小问题。

已有教程选打开/下载；再次生成会新建请求。未知提交先查原任务、取回原结果，不要连续重试。程序存活且电脑开机才有自动检查机会，不会自动生成长教程。

## 7. 可选功能与保存资料

GitHub Token可不填，公开仓库可匿名读取；403/429时先看限流。SMTP也可不配置，不影响采集和模型研究。需要邮件时才填服务商真实参数和授权码；本指南不要求发测试邮件。启用邮件后，到期任务可能发送当前周报。

重启前等任务结束，网页Key重启后重填。升级前关闭桌面、网页及计划任务写入者，备份`config.local.yaml`和整个`data/`，更新源码时保留它们，不用默认配置覆盖个人设置。系统凭据不会随文件自动迁移。

## 附录：新电脑最短安装

先安装Conda，取得所需版本源码，在含`pyproject.toml`的根目录执行；同名专用环境已存在时跳过第一条，不用base或`pip --user`：

```powershell
conda create -n github-stars python=3.11 pip -y
conda run -n github-stars --no-capture-output python -s -m pip install --no-user -e .
conda run -n github-stars --no-capture-output python -s -m pip check
conda run -n github-stars --no-capture-output python -s -m github_stars --check-environment
conda run -n github-stars --no-capture-output python -s -m github_stars web --open-browser
```

环境检查应为`valid: true`、`user_site: false`。安装、端口、目录和计划任务详情见[主README](../README.md)；界面步骤见[网页端使用说明](网页端使用说明.md)。
