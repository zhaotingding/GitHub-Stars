# GitHub Stars++：快速上手与运行结果

适用版本：0.2.2。先看启动后的界面和已有结果，不用把所有按钮都点一遍。

1. **打开网页。** 双击桌面“GitHub Stars++ 网页版”，或在项目目录执行 `bash tools/start_web.sh`，再打开 `http://127.0.0.1:8765/`。启动后首先看到“项目库”。

2. **读一个项目。** 在“已保存的项目”里搜索 `every-embodied`，点击项目卡片。右侧查看介绍，展开“阅读项目原文”看README。上方“查找新项目”才会去GitHub收集新资料。

3. **看已有回答。** 点左侧“AI问答”，再点“以前问过的问题”。点击“查看来源”核对原文；想提新问题时再填写并发送。

4. **打开已有教程。** 在项目库搜索 `Embodied-AI-Guide`，选择 `TianxingChen/Embodied-AI-Guide`，点“下载已有教程”。打开HTML后就能看概念、流程和练习。

5. **看每周推荐。** 点“每周推荐”，选择已有的一周。需要保存时，导出HTML或Markdown即可。

如果找不到这些历史内容，先清空搜索并确认打开的是原安装目录；新安装没有这批历史资料，需要先采集或导入项目。打不开网页时重新运行启动器，具体安装与设置见[配置与部署指南](配置与部署指南.md)。

想换关键词，点项目库上方“设置关键词”，每行写一个普通词，再保存。更完整的设置见[简明配置指南](配置与部署指南.md)。重看已有结果不会新增AI调用，发送新问题或生成新教程会。
