### 本轮发现的问题与改动

1. 教程输出不足：第一次4000 Token输出被截断，原响应已保存，实际取回原结果仍是incomplete，没有自动重新生成。之后对另一份项目资料使用明确简短的验收提示词、6000 Token上限，得到完整教程和下载文件。
2. Agent长来源：补读后的8000字原文放不进6000字符输入预算，旧逻辑会整条舍弃。现在保留带来源编号、URL、SHA、采集时间的前缀，并明确标记截断；引用只允许指向这一步真正发送过的证据。修复后同样两次上限可完成补读与回答。
3. 归档收藏：来源原文到期后显示明确中文提示；取消到期收藏时清空旧答案，迟到的旧请求不会重新填回页面。两个DOM场景用完全隔离的浏览器fixture验证，没有额外模型调用。

## 1. 先认识这次试用

这是一份围绕“具身智能、VLA、机器人视觉感知”的网页端入门路线。你已有计算机视觉基础，可以把 GitHub Stars++ 当作个人项目阅读台：先收集相关仓库，再依据保存的 README 提问，最后回到原文核对。它不会替你安装仓库、训练模型或操控机器人。

本次在用户授权的约 5 元预算内，尽量体验常用功能：先采集、导入和阅读，再分别验证标准问答、短分析、教程及受限 Agent 等。收费步骤采用手动触发，做完一项就核对状态和用量。实际执行范围、每项结果与累计估算，以本文开头的真实验收记录为准；下面介绍操作方法，不预先承诺所有功能成功。

## 2. 启动、打开与关闭

在 WSL 的项目目录执行：

```bash
bash tools/start_web.sh
```

启动器在后台运行服务，并打开本机浏览器。默认地址是 `http://127.0.0.1:8765/`，已有同一资料目录的服务时会打开原服务。也可以在项目专用 Conda 环境运行：

```powershell
conda run -n github-stars --no-capture-output python -s -m github_stars web --open-browser
```

后一种方式需要保留终端。任务空闲时按 Ctrl+C 可关闭。WSL 启动日志位于 `data/web.log`。如果启动器提示端口占用，先检查已有服务，不必连续启动多个实例。

网页右上角有“刷新”、主题选择和“停止服务”。切换深浅主题会保存偏好；“刷新”读取当前状态，不重新提交生成任务。关浏览器标签页后，后台服务和任务可能继续运行；需要结束本机服务时使用“停止服务”，有研究任务时先等待或停止后续步骤。

## 5. 配置 API：先关闭自动，再允许手动

先到“设置 → 定时检查”取消“启用自动检查”，再到“初始分析”取消“打开项目时自动做首次短分析”，到“邮件推送”确认“启用每周邮件”关闭。完成后点“保存设置”。这些开关与模型开关不同：模型开启可以允许手动问答，同时保持自动任务关闭。

![关闭定时任务](images/embodied-trial-20261106/07_关闭自动任务.png)

![关闭自动短分析](images/embodied-trial-20261106/08_关闭自动分析.png)

然后进入“API连接”，选择文本模型凭据来源 `local`，填写账户可用模型，开启“启用模型 API”。网页输入的“模型 API Key”只进入当前应用进程，保存后输入框清空，不写入 YAML 或日志，也不会由接口回传给页面。留空会保留已有启动环境变量或系统凭据，不表示清除密钥。

本次已验证官方 Key 能完成认证请求；这只证明该次认证可用，不等同于后续问答已经生成成功。用户希望体验高级模型，因此后续统一采用账户可用的 `gpt-6.1-sol`，分别核对“初始分析模型 ID”“深入教程模型 ID”“研究模型 ID”和需要时的“截图解读模型 ID”。研究模型留空会沿用初始分析模型；为了便于复核，本次使用的具体模型以验收记录为准。

![API 连接设置；密钥输入框不展示密钥](images/embodied-trial-20261106/02_API连接.png)

“保存设置”本身不会请求模型测试。但如果自动检查仍开启，新的配置可能随后被到期任务使用。独立服务关闭后，网页临时 Key 需要重新提供；只关标签页不会清除仍在运行进程中的 Key。

## 6. 读懂本次额度，而后提交问题

“设置 → 项目研究”采用以下限制：

| 项目 | 本次值 | 含义 |
| --- | --- | --- |
| 每题最多模型调用（含图片） | 2 | 给标准问答、Agent 或读图保留有限步骤 |
| 每题最多工具动作 / PNG 截图 | 2 / 1 | 只允许少量本地补查与最多一张图 |
| 每周最多研究请求（含图片） | 10 | 所有研究步骤合计，不是六道题的承诺 |
| 每次输出 Token 上限 | 2000 | 上限不是必定输出的长度 |
| 每次输入字符上限 | 6000 | 控制提交的证据及辅助内容 |
| 每题估算费用上限 | 1.20 元 | 约束研究用途的本地预留估算 |
| 输入 / 输出费率 | 20 / 100 元每百万 Token | 按本次保守预算系数换算 |

![每题、每周和输入输出限制](images/embodied-trial-20261106/05_研究调用限制.png)

官方列出的 `gpt-6.1-sol` 文本费率为每百万输入 Token 2 美元、输出 Token 10 美元。本次用 **10 人民币/美元的保守预算系数**，所以在本地填 20 和 100；使用同模型读图时也按对应费率配置。这个系数不是实时汇率，也不是账户结算金额；这里只用它留出预算余量。[官方模型与价格说明](https://developers.openai.com/api/docs/models/gpt-6.1-sol)

![每题估算费用上限与本地费率](images/embodied-trial-20261106/06_研究预算与费率.png)

请求前，程序用输入的 UTF-8 字节数保守估计输入量，再加上最大输出量预留费用；执行中按预留与已知实际估算中的较大值累计。因此实际输出较短，也可能因预留不足而阻止下一步。费率为 0 表示未知，会阻止新收费步骤，不能填写 0 假装免费。

初始分析、深入教程、项目研究各有独立调用限制；研究的 1.20 元上限不覆盖另外两类。本次短分析输出上限 2000 Token、每周最多 1 次，教程最终输出上限 6000 Token、每周最多 2 次（包含首次截断请求）；具体值以最终保存配置为准。应用没有覆盖三类请求的统一人民币总闸门，约 5 元的总体验预算需要逐项累计核对。次数和 Token 上限不是整个账户的金额预算。

选定项目后，点击“围绕该项目提问”即可进入研究页并选择该项目范围。查看详情与 README 不会调用模型；网页本身不会因为点击项目卡片而自动生成分析。

## 8. 先用标准问答，回答一个小问题

进入“项目研究”，确认模式为“标准问答”，范围优先选择一个材料较完整的项目，例如已保存的 `datawhalechina/every-embodied` 或 `TianxingChen/Embodied-AI-Guide`。范围选“全部本地项目”时，程序从本地保存资料中检索，并不会即时搜索整个 GitHub。教程与资源导航型仓库适合梳理学习路径，不能当作已经部署机器人策略的证据。

可使用下面的问题，让结果短而容易核对：

> 只依据已保存 README，用三点说明：输入与输出、在机器人具身智能系统中的作用、第一次小实验需要核对的条件。每点给引用；缺少材料就明确说明。不要声称已经运行项目，总计不超过300字。

![标准问答表单：先核对模式与范围](images/embodied-trial-20261106/14_标准问答表单.png)

确认没有附件，也未勾选“仅本题允许读图”，再点一次“开始研究”。按钮会直接创建研究任务，没有额外收费确认。提交后等待状态更新；网页会定期读取后台进度，切换页面或刷新不会重新提交同一次任务。再次主动点击“开始研究”则是一个新问题，不能用它重看已有答案。

研究结束后，先看“已完成”“达到限制”“没有匹配资料”或“提交未知”等状态，再看正文。若为“没有匹配资料”，标准模式没有调用模型，需要补充相关本地项目；若缺证据，不要把模型的通用解释当作仓库已经支持的功能。

![研究结束后的页面，实际状态以本次记录为准](images/embodied-trial-20261106/16_研究结果.png)

回答中的 `[R…]` 等按钮是来源入口。点击后检查原文节选、仓库地址、版本 SHA 和采集时间，特别核对模型把“作者宣称”写成“已验证”的地方。“来源与执行记录”还可查看“资料组织与Star观测”和执行动作。某次只有一份 Star 快照时，不能据此判断增长趋势。

如果结果完成且值得保留，可点“收藏回答”；“有用”“不相关”反馈影响后续本地排序，不会训练模型。研究任务通常保留 7 天，收藏只长期保留回答和来源位置，原文与完整过程仍可能随原任务到期清理。

## 9. 免费重看、费用核对与中断恢复

日后点击“研究记录”中的原问题，可重看已有回答和引用；这不会新建模型请求。搜索、切换研究状态、收藏与反馈、查看已有周报、导出周报、下载已完成教程也不会新建模型请求。采集和导入访问 GitHub，与模型费用是两件事。

“运行记录”有两层：上方“本机操作”说明后台操作状态，下方“运行与用量”以 JSON 展示 `jobs` 与 `research_steps`。重点查看 `state`、`actual_model`、`input_tokens`、`output_tokens`、`cost`、`reserve`。其中研究 `cost` 是返回 Token 乘本地费率得到的估算，`reserve` 是预留；实际账单仍在模型服务账户核对。

![运行与用量；以实际记录核对是否新增请求](images/embodied-trial-20261106/18_运行与用量.png)

失败或未知请求也占每周次数。没有返回 Token 时表示未知，不能记为零费用。连接中断后先打开原记录，按可用按钮处理：

| 按钮 | 什么时候用 | 会不会新生成 |
| --- | --- | --- |
| 取回原结果 | 原响应已保存或有可查询的响应 ID | 读取/查询原响应，不重新提交生成 |
| 明确继续 | 已取回原步骤，还需要完成后续步骤 | 允许剩余的新调用，不重置原限额与时限 |
| 停止后续步骤 | 不想让研究继续 | 阻止后续步骤，已提交费用不能撤销 |

无响应 ID 的未知提交无法保证取回，程序不会自动重发。先核对原记录与服务账户，计入已经发生或可能发生的用量，再决定是否值得新建任务。不要为得到好看的截图连续点击“开始研究”“生成教程”或调高次数重试。

## 10. 继续体验短分析、教程、Agent 与图片

“初始分析”生成快速判断用途的短说明，已有完成结果通常复用。先选一份 README 充分的项目，再点一次，核对用途、与具身智能的关系、入门建议和限制。短分析在网页中显示结构化字段，不能把显示格式和生成失败混为一谈。

“生成教程”创建独立长教程，完成后再次点击会新建请求。想重读时点“下载已有教程”，不要点“生成教程”。下载 HTML 后可离线阅读概念、流程、实践与检查题；实践勾选只记录自己的进度，不表示程序运行过命令。输出上限过低可能导致内容未完成，应先看任务状态与原响应，不能靠连续重生成补齐。本次已完成一份简短验收教程并下载；另一次4000 Token的长教程发生截断，详见实测记录。

“受限 Agent”可以在本题冻结的本地资料内补查、读取较长节选和历史等；决策轮也占模型次数，不代表拥有网络搜索或执行代码权限。可问“根据当前项目资料，帮我安排从 CV 转入具身智能的三步学习路线，缺少证据请说明”。在“来源与执行记录”核对是否实际调用工具；模型直接回答并不证明工具补查已经测过。两次调用可能只够一次决策加一次回答，达到限制时保留已有记录即可。

PNG 需要每题明确勾选“仅本题允许读图”，仅支持验证通过的静态 PNG，每张最多 2MB，标准模式最多一张。先选一张不含凭据的流程图，再提问“只描述图中可见模块及连接关系”。首次读图加回答通常至少需要两次剩余调用，并共用本题金额上限。成功与否应同时检查图片步骤和最终回答；未实际提交的附件不能算读图验证。

“每周精选”需要最近七天内完整成功的采集；资料不足时不凑数。本页“生成本周精选”执行本地筛选，已有本周周报会复用；选择历史期次后可“查看周报”“导出HTML”或“导出Markdown”。这不意味着自动邮件已经开启。

![每周精选入口与导出、邮件按钮](images/embodied-trial-20261106/19_每周精选.png)

“发送周报”会使用已启用的 SMTP 配置实际发送；“明确重发”可能重复投递，必须先检查原状态和收件箱。SMTP 接受也不等于进入收件箱。本次保持自动邮件关闭；是否有单独执行的明确邮件测试，以实测首页为准，没有投递证据就不能写成已送达。

## 11. 每天十分钟的学习方法

每天先用两分钟浏览一个项目的简介与 README，定位任务、输入输出和主要入口；再用三分钟把它放到机器人系统中：它负责感知、策略、数据采集还是执行，和已有 CV 知识有什么关系。

接着用三分钟核对一条关键结论，例如支持什么观测、动作如何表示、最小示例需要哪些数据或硬件；材料没写就记录“待核实”。最后两分钟更新研究状态，写下一条下次要回答的问题。多数日子直接阅读已有材料；只有存在明确证据缺口且愿意付费时，再规划一次短问答。

第一周可以依次梳理“具身系统输入输出”“机器人视觉与语言如何接入”“数据与动作表示”“最小实验条件”“项目之间的分工”。每周精选用于决定下周读哪一两项，不必把所有候选都生成教程。

## 12. 常见问题

**为什么保存 API 后还不能研究？** 检查模型开关、模型 ID、所选凭据来源、研究费率、每周次数和本题预算。认证通过不保证特定模型、参数或后续网络请求都可用。

**为什么已经采集，却没有匹配资料？** 采集可能只得到元数据，README 未读到，或者问题与本地材料不匹配。先检查具体项目原文，再导入明确相关仓库；不要反复提交空范围问题。

**为什么单题预算 1.20 元，实际看起来很少却被限制？** 额度判断使用保守预留，不只用最终输出量。多轮 Agent、读图加回答都会累计预留；缩小问题和证据范围可以减少输入。单题限制也不替代约 5 元的总体验预算。

**为什么周报没有项目？** 匹配分、活跃度、重复推荐冷却期和采集完整性都会影响入选；导入一个仓库不等于完成一次完整采集。

**网页关了任务会停吗？** 关标签页不停止后台任务；重新打开原服务查看状态。停止服务也不能撤销已经提交给模型的请求。

**回答能直接作为复现说明吗？** 先查引用和官方仓库，区分来源提供的步骤与模型建议。生成说明没有验证你的软件环境、硬件、代码运行或机器人安全条件。
