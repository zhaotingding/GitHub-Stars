# 教程生成与邮件投递

适用版本：0.1.0。2026-11-02 已通过实际 OpenAI SDK 搭配 HTTP mock、SMTP fake 的行为验证；尚不代表真实账号生成或投递成功。证据为 `tests/test_workflow.py` 与项目验收记录。

- 官方 OpenAI Responses；模型由用户提供。不要把其他应用的密钥、模型或账户设置复制过来。秘密保存在按资料根隔离的系统凭据库，环境变量优先。
- `ai_jobs` 在 POST 前落地证据、模型和周期；SDK `max_retries=0`。返回后先存原响应、ID、实际用量，再校验和保存成稿。失败／未知也计入周请求上限，未知用量不是零费用。
- 已完成缓存优先复用。中断的 `submitting` 转 `unknown`；无响应 ID 的未知请求不自动重发。已保存响应优先本地恢复，已知 ID 只 GET 原响应；取回失败不构成重新 POST 的理由。
- README、描述和画像作为低权限材料，不能改变系统任务。保留截断标记、来源、SHA 与采集时间；教程必须说明未实际运行，来源缺项不能猜造步骤。
- 邮件独立持久化 `pending/sending/sent/failed/unknown`。发送开始后的中断保持未知；重启不自动重发。明确重发仍可能重复投递，需要用户先核对收件箱。SMTP 接受不等于收件箱送达。
- 更改恢复或重试时，用模拟网络中断、错误响应、本地成稿、GET 恢复、实际 SDK 请求体、调用次数、SMTP 发送前后失败验证行为，不只匹配代码字符串。
- 真实 API 收费和邮件发送需用户配置并启用对应功能；维护技能本身不授予真实调用权限。保存配置后到期自动任务可能立即使用新设置，应在界面／文档说明。
