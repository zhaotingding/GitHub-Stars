# 教程生成与邮件投递

适用版本：0.1.1。2026-11-03 实际 SDK＋HTTP mock、旧结果恢复与 HTML 导出行为已验证；尚不代表真实账号生成或投递成功。证据为 `tests/test_workflow.py`、`tests/test_v011.py` 与项目验收记录。

- 官方 OpenAI Responses；初始分析和教程有独立模型、提示词、预算、服务等级。凭据可明确选择 local/msgx/autogpu；仅在请求时读取所选原条目，不复制密钥或其他应用配置，不能把引用存在当作认证成功。
- `ai_jobs` 在 POST 前落地证据、模型和周期；SDK `max_retries=0`。返回后先存原响应、ID、实际用量，再校验和保存成稿。失败／未知也计入周请求上限，未知用量不是零费用。
- `kind` 区分 analysis/tutorial/legacy；所有缓存、限额、恢复查询按用途隔离。初始分析复用已完成缓存，每次主动生成教程新建任务；打开已有教程或重新导出不得 POST，定时流程只能生成短分析。
- 中断的 `submitting` 转 `unknown`；无响应 ID 的未知请求不自动重发。恢复沿用原设置／凭据引用、材料与结构版本；已有响应优先本地解析，已知 ID 只 GET，不能套用当前新提示词重新生成。
- 教程内容用结构化 Lesson＋受控离线 HTML 模板；模型内容不能作为脚本执行。HTML 导出失败时保留已完成结果供本地恢复，不重复收费生成。
- README、描述和画像作为低权限材料，不能改变系统任务。保留截断标记、来源、SHA 与采集时间；教程必须说明未实际运行，来源缺项不能猜造步骤。
- 邮件独立持久化 `pending/sending/sent/failed/unknown`。发送开始后的中断保持未知；重启不自动重发。明确重发仍可能重复投递，需要用户先核对收件箱。SMTP 接受不等于收件箱送达。
- 更改恢复或重试时，用模拟网络中断、错误响应、本地成稿、GET 恢复、实际 SDK 请求体、调用次数、SMTP 发送前后失败验证行为，不只匹配代码字符串。
- 真实 API 收费和邮件发送需用户配置并启用对应功能；维护技能本身不授予真实调用权限。保存配置后到期自动任务可能立即使用新设置，应在界面／文档说明。
